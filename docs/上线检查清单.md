## 上线当天流程

```
□ 1. 确认所有 P0 检查项通过
□ 2. 构建生产版本（pnpm build）
□ 3. 构建 Docker 镜像并推送
□ 4. 备份数据库
□ 5. 更新 docker-compose.yml 镜像版本
□ 6. docker-compose up -d
□ 7. 检查健康检查通过
□ 8. 冒烟测试核心流程（登录 → 生成笔记 → 查看 → 导出）
□ 9. 检查日志无异常报错
□ 10. 通知团队上线完成
```
