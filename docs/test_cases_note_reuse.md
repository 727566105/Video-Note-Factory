# 频道笔记复用功能测试用例

## 测试环境
- 后端: http://localhost:8483
- 前端: http://localhost:3015
- 测试用户: admin (密码 123456), bin (密码 123456)

---

## 测试用例 1：用户账号切换显示正确

**前置条件**: 已登录 admin 账号
**步骤**:
1. 检查侧边栏用户信息是否显示 "admin"
2. 退出登录
3. 用 bin 账号登录
4. 检查侧边栏用户信息是否显示 "bin"（而非硬编码的"王旭洋"）

**预期结果**: 侧边栏正确显示当前登录用户的 username

---

## 测试用例 2：订阅博主不自动同步别人的笔记

**前置条件**: bin 用户登录，admin 用户之前已订阅过某博主并生成过笔记
**步骤**:
1. 进入频道管理页 `/channels`
2. 订阅一个 admin 已订阅过的博主（如 "有什么好玩的B站号"）
3. 订阅成功后检查 toast 提示是否显示统计信息
4. 进入频道详情页 `/channel/bilibili/260538746`
5. 检查视频列表中的笔记列：
   - 大部分应显示"暂无"（bin 用户没有生成过）
   - 个别视频可能显示"可复用"（通过 API 跨用户检测）

**预期结果**: 
- 订阅成功后显示统计提示
- 视频列表不直接显示"已有笔记"，而是"暂无"或"可复用"

---

## 测试用例 3：生成笔记前预检功能

**前置条件**: bin 用户登录，某个视频已有其他用户生成的笔记
**步骤**:
1. 在首页输入一个已有笔记的视频链接（如 BV1RN9uBEEZu）
2. 点击"生成笔记"
3. 检查是否弹出"发现已有笔记"对话框
4. 点击"查看现有笔记"
5. 检查是否成功复用笔记（toast 提示"笔记已保存到我的笔记"）

**预期结果**:
- 弹出预检对话框，显示视频标题
- 点击查看后笔记被克隆到当前用户

---

## 测试用例 4：频道详情页快速预览笔记

**前置条件**: bin 用户登录，频道详情页有"可复用"标注的视频
**步骤**:
1. 进入频道详情页
2. 找到一个显示"可复用"的视频
3. 点击眼睛图标查看笔记
4. 检查弹窗是否正确显示笔记内容
5. 点击"保存到我的笔记"

**预期结果**:
- 弹窗正确显示笔记 markdown 内容
- 保存后笔记关联到当前用户

---

## 测试用例 5：主动生成新笔记（不复用）

**前置条件**: bin 用户登录
**步骤**:
1. 在首页输入一个已有笔记的视频链接
2. 点击"生成笔记"
3. 在预检对话框中点击"重新生成"
4. 检查是否正常启动生成任务

**预期结果**: 正常生成新笔记任务，不复用已有笔记
