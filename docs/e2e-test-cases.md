# videoNote E2E 测试用例

> 使用 Chrome DevTools MCP (`mcp__chrome__*`) 执行浏览器端到端测试。
> 前置条件：后端 `http://localhost:8483` 和前端 `http://localhost:3015` 已启动。

## 通用操作模式

```
1. mcp__chrome__new_page(url, isolatedContext="agent-N")  → 创建隔离浏览器
2. mcp__chrome__take_snapshot()                            → 获取元素 uid
3. mcp__chrome__fill(uid, value)                           → 填写表单
4. mcp__chrome__click(uid)                                 → 点击元素
5. mcp__chrome__wait_for(["文本"], timeout)                 → 等待验证
6. mcp__chrome__take_screenshot(filePath)                  → 截图留存
7. mcp__chrome__navigate_page(type="url", url=...)         → 导航页面
```

## 模块 1: AUTH 认证 (7 个用例)

### TC-AUTH-01: 正常登录（admin）

| 项目 | 内容 |
|------|------|
| 前置 | 后端和前端服务运行中 |
| 路由 | `/login` |

**步骤：**
1. `mcp__chrome__new_page(url="http://localhost:3015/login", isolatedContext="agent-0")`
2. `mcp__chrome__take_snapshot()` — 获取页面元素
3. `mcp__chrome__fill(username_uid, "admin")` — 填写用户名（id="username"）
4. `mcp__chrome__fill(password_uid, "123456")` — 填写密码（id="password"）
5. `mcp__chrome__click(submit_button_uid)` — 点击"登录"按钮
6. `mcp__chrome__wait_for(["VideoNote", "快捷添加笔记"], timeout=10000)`

**期望：** 页面跳转到 `/`，可见标题 "VideoNote" 和 "快捷添加笔记"
